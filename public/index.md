# Melonite

## A tool for the new CTO Superbuilder

Move extremely fast without compromising quality.

Melonite fixes the bad behavioral patterns of coding agents, allowing you to build much faster without compromising quality.

[Request an invite](https://app.melonite.ai/login). Melonite is currently in closed beta.

## Capabilities

### Verify

Melonite helps you define the right validation rules for your tasks and generalize them into project-level rules. The Verifier engine automatically runs those rules against a coding agent's work and presents its feedback at the end of the coding turn.

### Prompt Weave

Let Melonite weave the next prompt to your coding agent. It automatically factors in your rules and verifier criteria.

### Melonite Agent

Use the Melonite Agent to brainstorm new rules, choose the right rules for a task, or operate your coding agent in a loop until all criteria are met. The agent can gradually take on more of the work of operating your software factory.

### Watchers

Start a session-scoped Watcher that keeps your agent honest about what you care about, or let the Melonite Agent do it for you.

## Install

Melonite is available for macOS, Windows, and Linux. It is free, uses your existing subscriptions, and is open source under the MIT license.

```sh
curl -fsSL https://github.com/meloniteai/melonite-desktop/releases/latest/download/install.sh | sh
```
